The test controller is compiled only into explicit fault builds. The normal build has no control listener, environment polling or injected clock/capacity behavior. Local fault channels use inherited owned UNIX socket FDs, bounded commands and one-shot selectors, explicit reached/release events, and stop/disconnect cancellation. A missing reached event fails the schedule. Startup synchronization orders initial arming before any hook proceeds; later arming requires an earlier reached barrier or other explicit proof that the transition has not occurred.

Live clusters run serially under the existing ownership lock. Use explicit DRAM emulation, a fresh 64 GiB region and checked geometry, node-1 broker memory/CPUs and node-0 clients, bounded workload/log/memory budgets, and owned cleanup. Small component fixtures do not substitute for the real-path campaign. The [fault specification](2026-09-22-production-fault-plan.md) defines invariants and the distinction between reachable live sequencing and stronger synthetic schedules.
