# Refactored boundaries and supported invariants

The implementation remains a bounded single-host research prototype. The refactor extracts production components with explicit ownership and admission contracts. Header-only helpers below are called by production; configuration and session-table operations also have separately linked compilation units.

| Component | Production consumer | Contract |
|---|---|---|
| `common/configuration.*` / `embarcadero_configuration` | Broker and client | File/string parser shared; effective values resolve once; CLI overrides environment; workers see frozen configuration |
| `cxl_manager/shared_mapping.h` / `region_descriptor.h` | Head mapping and follower attachment | Head publishes one base; followers validate a bounded descriptor probe and map that base without replacing existing mappings; RAII unmaps failed initialization |
| `cxl_manager/region_layout.h` | Region construction, allocation, `--print-layout` | Checked arithmetic, per-region geometry, bitmap capacity, version/backend/base agreement before shared access |
| `embarlet/bounded_reservation.h` | BLog/PBR/commit paths | Race-safe reservation/rollover, same-reservation identity, bounded absolute sequence spaces, no half-reserved commit range |
| `embarlet/topic_session.cc` / `session_admission.h` / `topic_session_key.h` | Linked broker session admission and publication | Four `Topic` methods own lookup, claim, OPEN admission, and frontier publication; capacity fails visibly, entries are not reused, and fencing remains terminal |
| `common/support_contract.h` | Client mode checks and both broker topic admission paths | Scalar order/ACK/RF rules, complete configured replication membership, and matching running-chain configuration; no silent RF clamping |
| `embarlet/single_topic_admission.h` | Both topic creation paths | One distinct topic per region lifetime until shared GOI/CV ownership supports more |
| `network_manager/protocol.h` | Broker, publisher, and native fault driver | One declaration of the existing native wire ABI; size/offset assertions, no wire-format migration |
| `network_manager/framing.h` | Session negotiation | Fragmented prefix is never silently reclassified; bounded reads |
| `network_manager/batch_validation.h` | Broker ingress | Validate bounded envelope before allocation, body before publication; independent of cache-flush policy |
| `common/cancellable_queue.h` | Connection and legacy replication admission | Closing wakes blocked producers/consumers; queued owned resources returned for cleanup |
| `disk_manager/memory_replica_sink.h` | Legacy replication worker | One owned allocation, wrap before copy, reject oversized batches and allocation failure without replication progress; volatile overwrite semantics only |
| `common/fault_injection.*` | Explicit fault-enabled broker/client builds | Bounded inherited local control channel, matched one-shot barriers, startup handshake, and cancellation; disabled in ordinary builds |
| `tools/dev_cluster.py` | Local development | Explicit emulation, topology/resource checks, production layout query, owned process groups and unique region |

The normal network data path still receives into reserved BLog memory and claims PBR only after receiving and validating the complete payload. Component boundaries must not introduce an extra payload copy. Small test capacities run the same extracted reservation functions used by production, but do not constitute a full multi-process fault campaign.

Segment reclamation is deliberately disabled. Existing descriptors retain their bytes until the region is destroyed. Exhaustion fails closed; it is not sustainable operation. A complete reusable log requires proof that receives, held records, subscribers, replicas, and replay references have all released the relevant segment. Do not re-enable reuse merely to extend a throughput run.

Layout v5 adds a descriptor in the reserved space between ControlBlock and the completion vector. Offsets elsewhere remain unchanged. Attach requires matching geometry, backend, layout version, and virtual mapping base because legacy shared pointer fields still exist. The head selects a free candidate base or an explicit override. A follower first reads only the ready descriptor through a bounded read-only mapping, then maps the published base; a conflicting override or occupied address fails with an actionable error. Neither the normal nor compatibility mapping path uses destructive `MAP_FIXED`. Shared-memory file extent is checked before mapping. Physical device-DAX attachment still requires hardware validation. Use a fresh region; active-head replacement, attach during destructive reinitialization, and recovery from a prior region are unsupported. Head registration is withheld until region/listener initialization completes. `EMBARCADERO_CXL_ZERO_MODE=none` is rejected.

Commit/fence serialization covers the supported process-local authoritative sequencer. It does not implement physical writer fencing across hosts. Session exhaustion rejects new OPEN operations; no successful OPEN is returned without representable authoritative state. GOI exhaustion stops affected progress without generating an invalid order range or claiming durability.

OPEN reserves a session identity, not future BLog/GOI capacity or immunity from a concurrent fence. Exhaustion can follow payload reservation and speculative classification; stopping safely does not promise completion of outstanding work. Session frontiers are separately monotonic, not an atomic reader snapshot. PBR accounting assumes coherent, serialized observations of a monotonic consumer and at most `slots - 1` outstanding reservations. Restart/reset and noncoherent CXL observations require separate validation. Rollover assumes a common immutable segment grid, the caller's rollover mutex, and no address reuse.

The [support matrix](../support-matrix.md) distinguishes implemented research modes from qualified profiles. Replicated admission requires the full configured contiguous broker set; that immutable topology is passed to legacy workers. Missing members cause rejection or deferred follower attachment, not a smaller replication ring. Admission is not dynamic membership or failover fencing.

Shutdown drains heartbeat RPCs before invalidating their topic callbacks, closes network admission and workers before destroying topics, and keeps the shared mapping alive until its managers are destroyed. Closing a bounded queue returns queued owned resources for cleanup instead of adding a sentinel to a possibly full queue. Mapping and replication startup exceptions request control-plane shutdown. This does not promise arbitrary kernel I/O cancellation.

Durability remains sink-specific. Scalog's durable RPC rejects its memory-only mode. A successful memory-accounting or memory-copy experiment is not media-durable evidence. Disk syscalls blocked in the kernel cannot be made cancellable by a protocol stop flag.

The opt-in ORDER5 E2E audit consumes the production ordered-delivery path, checks exact counts, consecutive global positions, indexed single-session payload order, remaining payload contents, and duplicate/parser/gap counters. It deliberately adds work and is a correctness gate, not a throughput benchmark. Raw and audited throughput must not be mixed.

The `client-minimal` configure/build preset builds `throughput_test` with broker, baseline tools, baseline client support, benchmarks, and tests disabled. The client retains its heartbeat/session protocol dependencies but does not require baseline generated RPC headers or symbols. Both CLI and `Publisher::Init` reject baseline sequencers before starting workers or probing the network. `tools/build_support/check_minimal_client.py` checks the dedicated build's commands, generated headers, and symbols; it should not be interpreted as a target-only dependency check in a mixed build tree. The full default build retains research baseline tools.

The owned fault runner implements all twenty cases: eighteen core cases plus two production-client extensions (`ack_hwm_withheld` and `session_reopen_resubmit`). Native scenarios in `test/integration/` use the production wire path and read-only shared-region observers; ACK retirement and reopen cases use the real publisher. Implementation is not a passing live verdict: each case must identify its actual broker, client/driver, configuration, and run outcome. The runner checks `/proc/PID/exe` hashes at controlled barriers to catch executable replacement between preflight and launch. Their exact recorded schedules and results belong in the fault campaign report, not in a blanket correctness claim: helper concurrency fixtures do not prove a concurrently reachable sequencer schedule, memory-copy ACK2 is not durability, and a paused queue hook must be released before testing the actual shutdown wait. Rollover retention checks include delayed receive, five 64-slot PBR laps, three retained segments, and fresh replay of two old batches; they do not establish safe reclamation or sustained operation. Session-capacity coverage fills the real 4096-entry table. The RF3/ACK2 memory-copy shutdown case waits for authoritative publishable membership before topic admission. Concurrent synthetic commit/fence stress, intermediate-publication OPEN races, expanded shutdown waits, disk-failure injection, and multi-broker session schedules remain stronger follow-ups, not implicit outcomes of these cases.

The broader separation of ordering workers, persistence, transport, and client state remains incremental work. Session classification and commit/fence serialization still live in `topic.cc`; the four extracted methods do not relocate the entire session state machine. Existing unlinked `SegmentManager`/`BufferManager` implementations are not the authoritative allocation path.
